🔢 Mini Counter Project

A simple beginner-friendly JavaScript counter application built with HTML, CSS, and JavaScript.

🚀 Features
Increase number with + button
Decrease number with - button
Reset counter to zero
Prevents going below 0
Clean and minimal UI
Simple hover effects for better UX

🧠 What I learned
This project helped me practice:
DOM manipulation (getElementById)
Event listeners (addEventListener)
Basic state handling in JavaScript
Updating UI dynamically
Writing cleaner and reusable functions
